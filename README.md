# 「第四面墙」周刊

## 介绍

- 我们每个人都被自己所处的环境所限制和约束，观察和思考的视野或多或少都受到影响，这是在过去的几年中深深影响到我的，所以我尽可能在自己学习和工作的领域深耕，但是处除此之外也不断地通过"第四面墙"观察这个世界。

- 基于此，我想在每周会通过各种信息来源（主要是rss）精选20-30篇文章，覆盖技术、文化、社会等领域，记录所读、所知、所想。

- 对于我来说，「第四面墙」是一个打破信息壁垒的周刊，希望也能对其他人有一些帮助。
